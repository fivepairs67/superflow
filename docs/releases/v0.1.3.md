# SuperFLOW v0.1.3 - More Accurate SQL Focus, Better Web Editor Support

SuperFLOW v0.1.3 improves everyday SQL exploration across tabs, editors, and complex scripts.

## Highlights

- Open the side panel for the selected tab without opening it in unrelated Chrome windows.
- More reliable full-query capture in Bitbucket file views and Monaco-based editors such as OneCompiler.
- Improved SQL-to-graph and graph-to-SQL focus for supported Ace and Monaco editors.
- More precise JOIN, FILTER, and WINDOW highlights, including nested queries and grouped DROP + CREATE scripts.
- Improved logical graph connections, column lineage, and session recovery after navigation or extension reloads.
- Clearer setup, privacy, and troubleshooting documentation.

## Installation

Install or update through the [Chrome Web Store](https://chromewebstore.google.com/detail/superflow/jndkmgobfdidhgcmkakkdjdgamchgbij) once the update is approved.

For manual installation, download `superflow-extension-v0.1.3.zip`, extract it, open `chrome://extensions`, enable Developer mode, click Load unpacked, and select the extracted `superflow-extension-v0.1.3/` folder.

Click SuperFLOW on your SQL editor tab, enable access for that site, and select a graph node. If direct capture is unavailable, use Paste SQL.

## Notes

This remains a beta release. Superset SQL Lab is the reference experience; other websites and editor integrations are best-effort. Analysis runs locally and does not execute SQL. Unsupported syntax or missing schema metadata may limit graph and column-lineage accuracy.
