# SuperFLOW v0.1.4 - More Reliable Editor Switching

SuperFLOW v0.1.4 improves SQL capture and execution-state isolation when moving between files and query tabs.

## Highlights

- Capture the new SQL after Bitbucket file navigation without requiring a page refresh.
- Request a fresh full-editor snapshot after URL changes, even when the SQL text is unchanged.
- Exclude hidden Ace, CodeMirror, textarea, and DOM editor surfaces so an inactive query cannot replace the visible query, including on empty tabs.
- Accept execution events after same-document navigation while rejecting events from old pages or unrelated frames.
- Keep the full worksheet when executing a selection. Ignore late responses belonging to an earlier query or execution.
- Mark HTTP failures as failed instead of leaving their execution status as running.
- Make the zoom-in and zoom-out controls easier to recognize with larger, bolder icons.
- Refresh the fictional SQL examples and store demonstration assets.

## Validation

Type checking, 123 runtime regression tests, 42 SQL parser fixtures, release packaging, and extension build passed. The runtime suite includes 28 new tests for editor switching, navigation snapshots, and execution ownership. The existing parser-vendor duplicate-case build warning remains.

Live checks during investigation covered Superset SQL Lab query-tab switching and OneCompiler Monaco capture. The fixes were verified with automated regression tests. CodeMirror checks cover simulated editor/DOM behavior; full-document capture in virtualized CodeMirror 6 editors is not guaranteed.

## Installation

Install or update through the [Chrome Web Store](https://chromewebstore.google.com/detail/superflow/jndkmgobfdidhgcmkakkdjdgamchgbij) once the update is approved.

For manual installation, extract `superflow-extension-v0.1.4.zip`, open `chrome://extensions`, enable Developer mode, click Load unpacked, and select the extracted `superflow-extension-v0.1.4/` folder. If updating an existing unpacked installation, reload the extension. Refresh already-open editor pages once so their page-world hooks are replaced.

The store upload package is `superflow-chrome-store-v0.1.4.zip`, with `manifest.json` at the archive root.

## Notes

This remains a beta release. Superset SQL Lab is the reference experience; other websites and editor integrations are best-effort. Analysis runs locally and does not execute SQL. There are no new permissions or changes to data transmission in this release.
